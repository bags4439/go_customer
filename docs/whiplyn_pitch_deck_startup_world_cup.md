# Whiplyn Pitch Deck
## Startup World Cup format (4 min pitch + 2 min Q&A)

**How to use this file**
1. Create a new Google Slides deck (16:9 widescreen).
2. Copy each slide block below into one slide.
3. Stay within the **CHAR LIMIT** for each text box so fonts stay readable at 24–32pt.
4. Replace items marked **VERIFY** with your confirmed numbers before presenting.
5. Paste **Speaker notes** into Slides: View → Show speaker notes.

**Brand**
- Primary colour: `#378ADD`
- Background: white / `#F5F4F0`
- Font suggestion: DM Sans (matches app) or Arial for universal export
