Countries collection — one-time seed (CA_COUNTRY_01_DATA)
============================================================

Collection path: countries

Create a composite index (required for the client query) before or when prompted:
  Collection: countries
  Fields: isActive — Ascending, sortOrder — Ascending

In Firebase Console: Firestore → Indexes → Composite → add the fields above.
